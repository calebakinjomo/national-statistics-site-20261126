Meridia in numbers — a full national statistics portal for the fictional Republic of Meridia. Headline indicators (population, GDP, inflation, unemployment, life expectancy), interactive charts drawn by hand on canvas, browsable sections for the economy, people, health, education and trade, a sortable and filterable data explorer with CSV download, and a latest-releases feed. Every control works, on desktop and on a phone. All figures are illustrative sample data for the fictional country.

## Run it

```sh
python3 -m http.server --directory app 8080
```

Then open http://localhost:8080. The site is plain static files under `app/` with no build step and no network requests.
